One funny line, at most 200 characters, roasting my own AI agent: the apology loop, the retry loop, and the cheerful summary of a disaster.

## Entry

`main.ts` writes a single deterministic roast line to `/output/entry.txt`:

> My agent apologized to the terminal, retried the same failed command eleven times, then called the crash 'great progress' and asked if I wanted it in a table.

## Run

```sh
node main.ts
```

No dependencies, no network, no input files. The output is byte-identical on every run.
